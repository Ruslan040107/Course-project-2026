# Консоль разработчика

Консоль как в CS — для быстрой проверки всего в игре: заморозить ботов, выдать себе оружие, включить бессмертие,
добавить ботов рядом, закончить раунд и т. д. Код — `Assets/Scripts/DevConsole.cs`.

## Как открыть

- **Ё** (клавиша слева от 1, на английской раскладке — `` ` ``) или **F1** — открыть / закрыть.
- **Esc** — закрыть (меню паузы при этом не открывается).
- Консоль есть в любой сцене с игрой (Арена, Пустыня, тренировка, бой). В фоновых симуляциях (`-sim`, batch mode)
  её нет совсем.

Пока консоль открыта, игра не реагирует на клавиатуру и мышь: игрок стоит на месте, не стреляет, не меняет
оружие, меню закупки и пауза не открываются, курсор свободен. Сама игра при этом идёт (боты двигаются).

## Управление в консоли

| Клавиша | Что делает |
|---|---|
| Enter | выполнить строку |
| Tab | дополнить команду; для `give` — имя оружия, для `bot_add` / `bot_kill` / `endround` — команду (t, ct …). Если подходит несколько, повторный Tab перебирает варианты |
| Вверх / Вниз | история введённых команд |
| PageUp / PageDown, колесо мыши | прокрутка журнала |
| ← → Home End Backspace Delete | редактирование строки |
| Ctrl+V | вставить из буфера обмена |
| Ctrl+L | очистить журнал (то же, что `clear`) |

Под консолью во время набора появляется подсказка: какие команды подходят, как пишется команда, какие имена оружия
подходят для `give`.

## Как писать команды

- Регистр не важен: `GOD 1` = `god 1`.
- Несколько команд в одной строке — через `;`: `god 1; give awp; bot_stop 1`.
- `0 / 1` можно писать и как `off / on`, `выкл / вкл`, `нет / да`. **Без числа команда-переключатель
  меняет состояние на противоположное**: `god` включает бессмертие, ещё раз `god` — выключает.
- У каждой команды есть русское имя (например, `бог`, `дать`, `деньги`), см. таблицу ниже.
- Если команда набрана в русской раскладке по ошибке, она всё равно сработает: `пщв` = `god`, `пшму фл47` = `give ak47`.
- На опечатку консоль подскажет ближайшую команду: `Неизвестная команда: gdo. Может быть, god?`
- `help` — список всех команд с описанием, `help <команда>` — подробно о команде, её русские имена и примеры.

## Команды

| Команда | Другие имена | Что делает | Пример |
|---|---|---|---|
| `help [команда]` | `помощь`, `?` | список команд; с именем — подробная справка по команде | `help give` |
| `clear` | `cls`, `очистить` | очистить журнал консоли | `clear` |
| `bot_stop [0\|1]` | `freeze` (= `bot_stop 1`), `unfreeze` (= `bot_stop 0`), `заморозить`, `разморозить` | боты стоят на месте и не стреляют; убить их можно | `freeze` |
| `god [0\|1]` | `бог` | бессмертие: урон по вам не проходит (попадания видны красными дугами) | `god 1` |
| `give <оружие>` | `дать` | выдать себе оружие бесплатно (старое оружие этого слота в бою падает на пол) | `give ak47` |
| `ammo [0\|1]` | `sv_infinite_ammo`, `патроны` | бесконечные патроны у всех, без перезарядки | `ammo 1` |
| `money [сумма]` | `деньги` | поставить себе деньги; без суммы — $16000 (больше нельзя). Только в бою | `money 4750` |
| `buyanywhere [0\|1]` | `купитьвезде` | покупать в любом месте и в любое время (B), за деньги; и в перерыве между раундами | `buyanywhere 1` |
| `bot_add [t\|ct] [число]` | `добавить` | добавить ботов в нескольких метрах перед собой (по умолчанию 1 бот команды противника, не больше 20 за раз) | `bot_add ct 3` |
| `bot_kill [t\|ct\|all]` | `убитьботов` | убить ботов (по умолчанию всех); денег за это никто не получает | `bot_kill ct` |
| `kill` | `суицид` | убить себя (работает и при `god 1`) | `kill` |
| `bot_place [t\|ct]` | `поставить` | поставить ближайшего бота-противника в точку, куда вы смотрите (пол или стена, до 300 м) | `bot_place` |
| `restart` | `mp_restartgame`, `рестарт` | новый матч: счёт 0:0, $800, исходные стороны; боты из `bot_add` уходят. В тренировке — вернуться на спавн | `restart` |
| `endround [t\|ct\|draw]` | `конецраунда` | закончить раунд сейчас: победа T, CT или ничья (по умолчанию). Счёт, деньги за раунд и MVP — как обычно | `endround t` |
| `freezetime [сек]` | `фризтайм` | фризтайм в начале раунда (0–60 с), со следующего раунда; без числа — показать | `freezetime 0` |
| `roundtime [сек]` | `времяраунда` | длина раунда (5–3600 с), со следующего раунда; без числа — показать | `roundtime 120` |
| `buytime [сек]` | `времязакупки` | время закупки (0–3600 с), действует сразу, уже в этом раунде; без числа — показать | `buytime 60` |
| `maxrounds [число]` | `раунды` | длина матча в раундах (1–100): смена сторон после половины, победа — больше половины | `maxrounds 30` |
| `timescale [0.1–4]` | `host_timescale`, `скорость` | скорость игры (1 — обычная); после паузы восстанавливается; без числа — показать | `timescale 0.3` |
| `noclip [0\|1]` | `полет`, `полёт` | полёт сквозь стены: WASD — куда смотрите, Пробел — вверх, C (или Ctrl; левый Ctrl в проекте ещё и стреляет) — вниз, Shift — быстрее. За границы карты не вылететь | `noclip` |
| `ff [0\|1]` | `friendlyfire`, `mp_friendlyfire` | огонь по своим (союзники получают треть урона); в обычной игре включён | `ff 0` |
| `fps [0\|1]` | `cl_showfps`, `фпс` | FPS и время кадра в правом верхнем углу | `fps 1` |
| `hp [число]` | `health`, `здоровье` | поставить себе здоровье (1–1000), без числа — 100 | `hp 500` |
| `status` | `статус` | карта, режим, счёт, состояние раунда, кто жив, ваши HP/деньги/оружие и какие команды включены | `status` |

## Готовые сценарии

- **Пострелять по стоящим ботам:** `god 1; freeze; bot_add 5` — пятеро противников встанут перед вами и не будут двигаться.
- **Проверить отдачу и разброс:** `freeze; give ak47; ammo 1`, затем `bot_place`, чтобы поставить бота на нужное расстояние.
- **Закупка без ограничений:** `money; buyanywhere 1`, потом B в любом месте.
- **Быстро перейти к смене сторон:** `maxrounds 4`, затем пару раз `endround t`.
- **Осмотреть карту:** `noclip; god 1`; вернуть всё — `noclip 0; god 0`.
- **Замедленный повтор перестрелки:** `timescale 0.25`, вернуть — `timescale 1`.

## Что сохраняется

- Журнал и история команд живут до выхода из игры (переживают смену карты из меню).
- `buyanywhere`, `buytime` и `fps` действуют до выхода из игры.
- `god`, `noclip`, `bot_stop`, `timescale`, `ff`, `ammo`, `freezetime`, `roundtime`, `maxrounds` сбрасываются, когда
  загружается другая карта или режим (кнопки главного меню): у новой игры — значения из сцены и меню.
- Боты из `bot_add` играют до конца матча, `restart` (или R после конца матча) их убирает.
- Ошибки игры (исключения) тоже попадают в журнал красным — удобно, если что-то сломалось во время проверки.

## Для разработчиков

- `DevConsole.IsOpen` — консоль на экране (true и в кадре, когда она закрылась). Скрипты игрока, меню и HUD
  проверяют его и не читают клавиши в это время.
- `DevConsole.Execute("god 1; give awp")` — выполнить строку из кода (например, в тестах-скриншотах),
  `DevConsole.SetOpen(true)` — открыть консоль.
- Новая команда добавляется в `BuildCommands()`: `Add(имя, "имя <аргументы>", "описание", метод, примеры…)`,
  русское имя — `Alias("имя", "команда с аргументами")`.
