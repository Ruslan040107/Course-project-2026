# Характеристики оружия (от пользователя, 2026-10-19)

Пояснения:
- «Отдача» в %: чем выше, тем лучше контроль стрельбы (меньше отдача).
- «Скорость передвижения»: единицы CS, максимум 250 → множитель скорости = значение / 250.
- Урон по зонам: «в броне (без брони)». Брони в игре пока нет → используем значения БЕЗ брони; множители зон = урон зоны без брони / «Урон».
- Скорострельность в выстрелах в минуту (rpm) → fireRate = rpm / 60.
- Сторона: T = только террористы, CT = только спецназ, обе = все (как в CS2).
